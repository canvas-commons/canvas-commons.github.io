When the desired length is set to null it represents a default value for whatever property it describes.

Length​

type Length = number`${number}%`

Represents a length used by most layout properties.

The value can be either:

  • number - the desired length in pixels
  • ${number}% - a string with the desired length in percents, for example '50%'

RoughFillStyle​

type RoughFillStyle = 'hachure''solid''zigzag''cross-hatch''dots''dashed''zigzag-line'

Fill style options for rough shapes.

  • hachure: Parallel lines filling the shape (default)
  • solid: Solid fill with slight irregularity
  • zigzag: Zigzag pattern filling
  • cross-hatch: Crossed parallel lines
  • dots: Dotted pattern filling
  • dashed: Dashed lines filling
  • zigzag-line: Zigzag lines filling

TextAlign​

type TextAlign = CanvasTextAlign'justify'

Line-level text alignment. Extends CanvasTextAlign with 'justify', which distributes line-end slack across word gaps. Justification only affects non-last lines of a paragraph; the last line falls back to the start orientation.

TextExclusion​

type TextExclusion = TextShapeExclusionhorizontalPadding?: numberkind: 'node'node: SignalValueNodeverticalPadding?: number

A region of a <Txt> block that text wraps around. Coordinates are Txt-local and center-origin, the same space every other node uses. A node exclusion instead reads its shape from a live Node.

TextShapeExclusion​

type TextShapeExclusion = height: numberhorizontalPadding?: numberkind: 'rect'verticalPadding?: numberwidth: numberx: numbery: numberhorizontalPadding?: numberkind: 'polygon'points: x: numbery: number[]verticalPadding?: number

A region of a <Txt> block that text wraps around, given by its own geometry. A rect's x/y is its center and polygon points sit in the same space.

TextWrap​

VerticalAlign​

type VerticalAlign = 'top''middle''bottom'

Vertical placement of text when the rendered text block is shorter than the configured height. 'top' (default) aligns to the top edge, 'middle' centers, 'bottom' aligns to the bottom edge.
