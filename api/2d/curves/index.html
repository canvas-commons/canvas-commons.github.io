createCurveSampler​

public createCurveSamplerprofile: CurveProfile: distance: number => CurvePoint

Create an arc-length sampler over a profile. Calls with non-decreasing distances are amortized O(1). A smaller distance rescans from the start.

Parameters

  • profile: CurveProfile

    The profile to sample.
